## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024×1024, 211,120 bytes) to `/output/entry.png`, or to `$MAKEFUN_OUTPUT_DIR/entry.png` when that is set. The image is rendered by `render25.py` (Pillow, DejaVu fonts, no network); `main.py` only copies the bundled image after checking its PNG magic, IEND trailer, dimensions and the 1 MiB limit.
